How rivalry scores work

Every head-to-head game counts. Regular season games count 1. Playoff games count more each round: round 1 counts 2, round 2 counts 3, and so on up to the title game.

Balance measures how even the series is, using the same weights: 1 means dead even, 0 means one owner won every time.

Rivalry score = weighted games × (0.5 + 0.5 × balance). Each owner's top 2 scores are their rivals, with ties going to whoever they've played more.
